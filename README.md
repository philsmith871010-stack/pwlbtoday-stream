# pwlbtoday-stream

**PWLBpulse · CouncilIntel** — one page, three tabs:

- **Pulse** — the live **markets · economics · council-news** stream, newest
  first. One card per item, sub-filter pills, pagination.
- **Councils** — search a council to see its assembled position: summary,
  signals, dated key figures with page references, and its document trail.
  Plus the cross-council signals board and the latest documents caught.
- **Counterparty** — the sortable per-council lending-limit table the
  inter-authority market prices on.

Live page: https://philsmith871010-stack.github.io/pwlbtoday-stream/

Built by `monitor/site/build_platform.py` (CouncilIntel repo): Pulse data from
the pwlbtoday-watch archive, council data from CouncilIntel. The standalone
council explorer remains at `/councils/` as a deep-link fallback. Do not edit
`index.html` by hand. Times UK.
